# optofidelity_protocols

This project holds shared code that used for communication between the other
optofidelity robot testing projects:
[optofidelity_chromeos_touch_sender](https://chromium.googlesource.com/chromiumos/third_party/optofidelity_chromeos_touch_sender/),
[optofidelity_TPPT](https://chromium.googlesource.com/chromiumos/third_party/optofidelity_TPPT/),
and
[optofidelity_TPPT_analysis](https://chromium.googlesource.com/chromiumos/third_party/optofidelity_TPPT_analysis/).

It is included as a submodule in those projects.
